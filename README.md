# 🐍 U.S. States Geography Game

An interactive, educational game built in Python using the `turtle` and `pandas` libraries. Test your geographical knowledge by guessing all 50 states of the US on a blank map!

## ✨ Features
- **Interactive Map:** Uses the `turtle` module to place state names exactly where they belong on the US map.
- **Data Handling:** Reads state coordinates and names seamlessly using the `pandas` library.
- **Smart Learning:** Type "Exit" at any point, and the game will automatically generate a `missin_states.csv` file with all the states you missed, so you can learn them for next time!

## 🎮 How to Play
1. A prompt will ask you to enter a state's name.
2. If your guess is correct, the state's name will appear on the map.
3. Try to reach 50/50!
4. Type **Exit** to leave early and generate your study list.

## 🚀 How to Run
1. Make sure you have **Python 3** installed.
2. Install the `pandas` library if you haven't already:
   ```bash
   pip install pandas
   ```
3. Clone the repository and run the game:
   ```bash
   git clone [https://github.com/sagishaham2/US-STATES-GAME.git](https://github.com/sagishaham2/US-STATES-GAME.git)
   cd US-STATES-GAME
   python3 main.py
   ```
